# Falling Pickaxe как Telegram Mini App — установка

Игра остаётся обычным статическим сайтом (HTML + JS + картинки + звуки). Telegram просто открывает этот сайт внутри мессенджера. Поэтому весь процесс сводится к двум шагам:

1. Выложить папку игры на любой хостинг с **HTTPS**.
2. Создать бота в @BotFather и указать ему адрес игры.

Бэкенд, база данных и платные сервисы не нужны.

---

## Что изменено в игре

| Файл | Что сделано |
|------|-------------|
| `telegram.js` (новый) | Подключение к Telegram WebApp API: раскрытие на всю высоту, запрет закрытия свайпом, подтверждение при закрытии, цвета шапки, вибро-отклик на кнопки, пересчёт раскладки при смене размера окна |
| `index.html` | Подключены `telegram-web-app.js` (официальный скрипт Telegram) и `telegram.js` |
| `style.css` | Небольшой блок стилей в конце файла (`/* Telegram Mini App */`) |
| `sw.js` | Обновлена версия кэша, добавлен `telegram.js` |
| `bot/` (новая папка) | Необязательный пример бота на Python с командой `/start` и кнопкой «Играть» |

Если открыть игру в обычном браузере, `telegram.js` ничего не делает, и игра работает как раньше.

## Шаг 1. Разместите игру на HTTPS-хостинге

Telegram открывает Mini App только по адресу `https://...`. Выберите один из вариантов.

### Вариант A. GitHub Pages (бесплатно)

1. Зарегистрируйтесь на https://github.com и нажмите **New repository**.
2. Назовите репозиторий, например `falling-pickaxe`, сделайте его **Public**, нажмите **Create repository**.
3. Нажмите **uploading an existing file** и перетащите **содержимое** папки `falling-pickaxe-web` (не саму папку: `index.html` должен лежать в корне репозитория). Папки `assets` и `bot` перетаскивайте вместе с файлами.
   - Если браузер не принимает много файлов за раз, загружайте частями или используйте git:
     ```bash
     cd falling-pickaxe-web
     git init
     git add .
     git commit -m "Falling Pickaxe"
     git branch -M main
     git remote add origin https://github.com/ВАШ_ЛОГИН/falling-pickaxe.git
     git push -u origin main
     ```
4. Откройте **Settings → Pages**. В разделе *Build and deployment* выберите **Source: Deploy from a branch**, ветку **main**, папку **/ (root)**, нажмите **Save**.
5. Через 1–2 минуты сайт будет доступен по адресу:
   `https://ВАШ_ЛОГИН.github.io/falling-pickaxe/`
6. Откройте этот адрес в браузере и убедитесь, что игра запускается. Это и есть ваш `WEBAPP_URL`.

### Вариант B. Netlify (самый быстрый)

1. Откройте https://app.netlify.com/drop.
2. Перетащите папку `falling-pickaxe-web` в окно браузера.
3. Через несколько секунд получите адрес вида `https://случайное-имя.netlify.app`. Его можно сменить в *Site configuration → Change site name*.

### Вариант C. Cloudflare Pages / Vercel

Подойдут любые: создайте проект, загрузите папку, в настройках сборки оставьте **Build command** пустым, а **Output directory** — корень (`/` или `.`).

### Вариант D. Свой сервер (VPS)

1. Скопируйте папку в `/var/www/pickaxe`.
2. Настройте nginx и получите сертификат Let's Encrypt (`certbot --nginx -d ваш.домен`).
3. Минимальный конфиг:
   ```nginx
   server {
       listen 443 ssl;
       server_name ваш.домен;
       root /var/www/pickaxe;
       index index.html;
       # ssl_certificate ... добавит certbot
   }
   ```

> Самоподписанные сертификаты и адреса `http://` Telegram не принимает. Адрес `localhost` тоже не подойдёт, для теста см. раздел «Локальная проверка» ниже.

## Шаг 2. Создайте бота и подключите игру

### Способ 1. Только через @BotFather (без кода, рекомендуется)

1. В Telegram откройте **@BotFather** и отправьте `/newbot`.
2. Введите отображаемое имя (например, `Falling Pickaxe`), затем username, который заканчивается на `bot` (например, `FallingPickaxeGameBot`).
3. Сохраните выданный **токен**. Не публикуйте его.
4. Отправьте `/newapp`, выберите своего бота и пройдите шаги:
   - **Title** — название игры.
   - **Description** — краткое описание.
   - **Photo** — картинка 640×360 px (можно сделать из любого скриншота игры).
   - **GIF** — можно пропустить командой `/empty`.
   - **Web App URL** — адрес из шага 1 (`https://...`).
   - **Short name** — короткое имя для прямой ссылки, например `pickaxe`.
5. BotFather пришлёт ссылку вида `https://t.me/FallingPickaxeGameBot/pickaxe`. По ней игра открывается как Mini App.

Чтобы игра запускалась кнопкой «Play» рядом с полем ввода в чате с ботом:

1. Отправьте BotFather `/mybots` → выберите бота → **Bot Settings** → **Menu Button** → **Configure menu button**.
2. Укажите тот же `https://`-адрес и название кнопки, например `⛏ Играть`.

### Способ 2. Бот с командой /start (папка `bot/`)

Бот отвечает на `/start` сообщением с кнопкой «Играть» и сам настраивает кнопку меню.

1. Установите Python 3.9 или новее.
2. Откройте терминал в папке `bot`:
   ```bash
   cd bot
   python3 -m venv venv
   source venv/bin/activate          # Windows: venv\Scripts\activate
   pip install -r requirements.txt
   ```
3. Задайте переменные окружения (токен из @BotFather и адрес игры):
   ```bash
   export BOT_TOKEN="123456:ABC-DEF..."
   export WEBAPP_URL="https://ВАШ_ЛОГИН.github.io/falling-pickaxe/"
   ```
   На Windows (PowerShell):
   ```powershell
   $env:BOT_TOKEN="123456:ABC-DEF..."
   $env:WEBAPP_URL="https://ВАШ_ЛОГИН.github.io/falling-pickaxe/"
   ```
4. Запустите бота:
   ```bash
   python bot.py
   ```
5. Откройте своего бота в Telegram, отправьте `/start` и нажмите **⛏ Играть**.

Бот должен быть запущен только если вам нужна команда `/start`. Сама игра (ссылка из `/newapp` и кнопка меню, настроенная в BotFather) работает без запущенного бота.

Чтобы бот работал круглосуточно, запустите его на VPS или на бесплатном хостинге для Python-приложений (Railway, Render, Fly.io и т.п.). Токен и адрес передавайте через переменные окружения хостинга, не храните их в коде. Для systemd на VPS:

```ini
# /etc/systemd/system/pickaxe-bot.service
[Unit]
Description=Pickaxe Telegram bot
After=network.target

[Service]
WorkingDirectory=/opt/pickaxe/bot
Environment=BOT_TOKEN=123456:ABC-DEF...
Environment=WEBAPP_URL=https://ваш.домен/
ExecStart=/opt/pickaxe/bot/venv/bin/python bot.py
Restart=always

[Install]
WantedBy=multi-user.target
```
```bash
sudo systemctl enable --now pickaxe-bot
```

## Проверка

1. Откройте ссылку `https://t.me/ВАШ_БОТ/short_name` на телефоне.
2. Игра должна раскрыться на всю высоту окна, а первый тап включит звук.
3. Проверьте кнопки SPIN, BET, AUTO, BONUS BUY и смену мира (WORLD).
4. Проверьте десктопную версию Telegram: окно будет узким, но игра рассчитана на вертикальную раскладку.

### Локальная проверка (необязательно)

Чтобы проверить игру на компьютере до загрузки на хостинг:

```bash
cd falling-pickaxe-web
python3 -m http.server 8080
```

Откройте `http://localhost:8080` в браузере. Для проверки внутри Telegram нужен HTTPS-туннель, например:

```bash
cloudflared tunnel --url http://localhost:8080
# или
ngrok http 8080
```

Полученный `https://...`-адрес можно временно указать в @BotFather. Для тестовой среды Telegram у BotFather есть отдельная настройка, но для этой игры хватит обычного режима.

## Обновление игры

1. Измените файлы и загрузите их на хостинг (GitHub: новый commit/push, Netlify: повторный drag-and-drop).
2. Если игрок видит старую версию, увеличьте номер кэша в `sw.js`: замените `fp-tg-v1` на `fp-tg-v2` и т.д., затем загрузите файл.
3. Адрес в @BotFather менять не нужно, пока он не изменился.

## Частые проблемы

| Симптом | Причина и решение |
|---------|-------------------|
| Белый или пустой экран | Файлы загружены вложенной папкой. `index.html` должен открываться по корню адреса. Проверьте адрес в обычном браузере |
| BotFather пишет «invalid URL» | Адрес начинается не с `https://` или недоступен |
| Нет звука | Звук включается после первого касания экрана. Проверьте кнопку звука в игре и беззвучный режим телефона (на iPhone) |
| Игра не раскрывается на весь экран | Обновите Telegram. Раскрытие поддерживается во всех актуальных версиях. Для настоящего полноэкранного режима в `telegram.js` установите `FULLSCREEN = true` (нужен Telegram 8.0+) |
| Игра показывает старую версию | Увеличьте версию кэша в `sw.js` (см. «Обновление игры»). На iOS service worker в Telegram может не работать, это не влияет на игру |
| Бот не отвечает на `/start` | `bot.py` не запущен, неверный токен или не заданы `BOT_TOKEN` и `WEBAPP_URL` |
| Мало места на хостинге | Самые тяжёлые файлы лежат в `assets/images/backgrounds/` (около 1,5 МБ каждый). Удалите ненужные миры или сожмите PNG |

## Важные замечания

- **Валюта в игре демонстрационная** (`CASH (DMO)`), баланс по умолчанию 50 000 и сбрасывается при каждом запуске. Настройки (мир, шейдеры и т.д.) сохраняются в `localStorage` Telegram.
- Игра имитирует механику слота со ставками. Пока она работает на демо-валюте без вывода и покупки, это безопасно. Если вы добавите реальные деньги, Telegram Stars, TON или любые призы, потребуются лицензия на азартные игры и соблюдение правил Telegram и закона вашей страны.
- Графика, звуки и шрифт в сборке взяты из публичной демоверсии стороннего проекта (см. `README.md`). Для публичного запуска проверьте, что у вас есть права на эти материалы, или замените их своими.
- Скрипт `https://telegram.org/js/telegram-web-app.js` подключается с серверов Telegram. Это официальный способ, и внутри Telegram он всегда доступен.
